# Подбор автозапчастей и аналогов

Клиент к API [Favorit Parts](https://lk.favorit-parts.ru/static/wsprice.pdf). Подбор идёт в два шага: по артикулу приложение находит производителей, а после выбора производителя показывает цены и остатки по самой детали и её аналогам.

**Стек:** React 19, Redux Toolkit + RTK Query, antd 6 (формы, таблицы), Tailwind CSS 4, Vite. Без TypeScript.

## Запуск

```bash
echo FAVORIT_API_KEY=00000000-0000-0000-0000-000000000001 > .env   # демо-ключ из документации API
npm install
npm run dev
```

## Деплой на Vercel

1. Импортируйте репозиторий. Vercel сам определит Vite: сборка `npm run build`, результат в `dist`.
2. В Settings → Environment Variables добавьте `FAVORIT_API_KEY`.

API доступно только по HTTP, поэтому браузер напрямую обращаться к нему не может: страница на HTTPS получит ошибку mixed content. Запросы идут через функцию [`api/parts.js`](api/parts.js), она же подставляет ключ на сервере. В dev то же самое делает прокси Vite.

## Что обрабатывается

- Загрузка: спиннер при первом запросе. При повторном старые данные остаются на экране.
- «Не найдено»: API возвращает запись-заглушку, мы её отфильтровываем и показываем пустое состояние.
- Ошибки API (`{ "error": "..." }`, например превышена квота или неверный ключ), сбой сети, таймаут, 5xx: сообщение на русском и кнопка «Повторить».
- Цена 0 показывается как «Цена по запросу», остаток 0 — как «Нет в наличии».
